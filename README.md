# Zoo Digital

Zoo Digital é um projeto desenvolvido em **Java** para modelagem de diferentes animais e seus comportamentos utilizando conceitos de Programação Orientada a Objetos.

O projeto organiza os animais em diferentes categorias e utiliza herança e interfaces para representar características e comportamentos específicos de cada espécie.

## Funcionalidades

* Modelagem de diferentes espécies de animais
* Organização dos animais através de herança
* Utilização de classes abstratas
* Implementação de comportamentos através de interfaces
* Sobrescrita de métodos para comportamentos específicos
* Geração de identificadores individuais para os animais

## Tecnologias

* Java
* Maven

## Contexto

Projeto desenvolvido durante a graduação em **Ciência da Computação** como atividade prática para aplicação de conceitos de Programação Orientada a Objetos, incluindo herança, abstração, interfaces e polimorfismo.
